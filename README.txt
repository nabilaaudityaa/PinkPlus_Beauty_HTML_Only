PINK+ BEAUTY - VERSI HTML

Cara pakai:
1. Extract ZIP.
2. Buka folder di VS Code.
3. Buka index.html di browser. Paling nyaman: install extension Live Server di VS Code lalu klik kanan index.html > Open with Live Server.
4. Tidak perlu XAMPP, PHP, atau MySQL.

Fitur:
- Homepage pink/feminin
- Kategori dan filter
- Keranjang dengan localStorage
- Checkout
- Struk
- Cetak / Save as PDF
- WhatsApp otomatis

GANTI NOMOR WA:
Buka index.html, cari:
const WA="6281234567890";
Ganti dengan nomor toko tanpa +, spasi, atau tanda -.

Catatan: versi HTML ini tidak memakai database online. Data keranjang tersimpan di browser. Cocok untuk demo/tugas/front-end. Untuk toko online sungguhan diperlukan backend/database/hosting.
